Esse projeto de análise de dados foi realizado com o objetivo de identificar a loja com o melhor desempenho e os produtos mais populares de cada uma dessas lojas. 
Estrutura:
Importação de dados;
Vendas por Categoria cálculo;
Média de Avaliaçaõ das lojas;
Produtos mais e menos vendidos;
Frete médio das lojas;
Média de avaliação das lojas;
Gráficos e Resultados.
